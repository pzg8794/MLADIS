# EIN And Banking Package

Private preparation notes for EIN, banking, bookkeeping, and direct-booking readiness.

## EIN Status

- EIN application status: Issued on 2026-06-03.
- IRS confirmation letter status: Saved in private local business records, not in Git.
- Use only the official IRS EIN tool for EIN work: https://www.irs.gov/ein
- IRS says EIN applications are free and third-party paid EIN websites should be avoided.
- IRS says the legal entity should be formed with the state before applying for an EIN. MLADIS LLC is approved/issued in NYBE.

## Files

- `ein-worksheet.md` - values to have ready before opening the IRS EIN Assistant.
- `bank-account-checklist.md` - documents and controls for opening a business bank account.
- `bank-account-opening-packet.md` - bank-ready cover package and application-answer guide.
- `business-bank-cover-letter.md` - short cover letter to include if a bank or fintech asks for an upload/letter.
- `private-records-manifest.md` - private storage checklist for EIN/banking records without the EIN value.
- `bookkeeping-chart-of-accounts.md` - starting categories for bookkeeping.

## Sensitive Data Rule

Do not enter SSN, ITIN, EIN, bank account numbers, card numbers, or identity-document numbers in this repo. Put those only into the official IRS/bank/provider form when you are on the real site.
