## Scope

This release deploys the independently reviewed marketing funnel from
application source commit `75b19841f54010ffa1daa1dca8397afd4a72eacc`.
The release manifest is the only change after that approved source commit;
the `airbnb_agent/` Git tree must remain identical. The deployment archive
contains the Django application and excludes production `.env`, `.venv`,
`db.sqlite3`, `media/`, `staticfiles/`, and runtime backups.

scope. C09 remains held. This release does not publish campaigns or enable
