## Deployment Contract

Deploy through the root-level VM script only:

```bash
./deploy_mladis_vm.command
```

The deployment is non-destructive. It must not overwrite production `.env`,
`.venv`, `db.sqlite3`, `media/`, or runtime backups. The script creates a VM
runtime backup, installs requirements, applies existing migrations, synchronizes
social applications, provisions the automation admin, collects static assets,
runs Django checks, and restarts the `mladis` service.
