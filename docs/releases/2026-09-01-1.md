## Scope

This release restores the approved operations-page implementations already
recorded in Git, keeps their real API-backed data connections, and removes the
retired page implementations from the production filesystem. Exact source
fingerprints and route contracts prevent the generic legacy pages from being
released again through normal CI.

The release also makes Stripe `auto` mode resolve to test mode inside Django's
test runner. Production host and environment resolution remains unchanged and
continues to reject mismatched live/test credentials.

No production secret, reservation, payment record, listing, authentication
credential, or database model is changed by this release.

## Known Limitations

- The frontend build reports the existing Node 23 engine warning; the project
  dependencies request Node 20.19, 22.13, or 24 and later.
- `npm audit` reports six dependency findings (one low and five high); this
  release does not modify dependency versions.
- Vite reports the existing large-bundle warning and leaves the six-bedroom
  stay image URL for runtime resolution.
- PayPal credentials are not configured, so PayPal deposit checkout displays
  its setup message instead of creating a payment.
- The configured console email backend logs email locally and does not deliver
  messages to guests.
