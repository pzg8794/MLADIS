## Scope

This patch preserves the payment lifecycle work in Release 2026.08.12-4 and
normalizes Stripe SDK webhook objects at the service boundary. Stripe signature
verification returns nested `StripeObject` instances rather than plain Python
dictionaries; payment, damage-deposit, and donation lifecycle handlers now
consume one normalized event representation.

No database migration, authentication change, UI change, payment amount change,
or deployment-environment secret is included in source control.

## Post-Deployment Verification

After deployment, MLADIS must accept a correctly signed webhook and return HTTP
200. A live Stripe `payment_intent.canceled` event may be generated using an
unconfirmed USD 0.99 PaymentIntent so delivery and reconciliation can be tested
without authorizing, capturing, or refunding money.
