## Scope

This release makes booking-agent answers concise and readable in the customer
interface, strips raw Markdown emphasis/code markers at the presentation
boundary, and records the feature verification ledger used to distinguish
implemented, locally tested, and production-tested functions.

The release tag also contains intervening documentation-only DR evidence
commits. The VM deployment archive contains only `airbnb_agent`, so those
business records do not affect production runtime behavior.

No authentication, payment, database model, migration, secret, or OAuth
configuration is changed by this release.

## Manual Verification

At `https://local.mladis.com/`, a temporary authenticated QA guest submitted
two booking-agent questions. The backend recorded `agent_mode=openai` with
model `gpt-5.4-nano`. The final answer was concise, same-language, and rendered
without raw Markdown markers. The QA user was deleted after verification.

## Known Limitations

- A Google Maps widget metadata request emitted an unrelated browser network
  error during the local canary.
- The feature ledger intentionally retains `NOT_TESTED` and `BLOCKED` states
  for functions that have not been executed on this release.
- This release does not claim that every MLADIS function works.
