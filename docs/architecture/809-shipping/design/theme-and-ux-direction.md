# Theme and UX Direction

809 Shipping should inherit the MLADIS platform philosophy while developing a distinct logistics identity.

## Brand feel

```text
Reliable
Caribbean-connected
Modern
Operationally intelligent
Friendly for customers
Powerful for staff
```

## Visual language

Use the same premium SaaS direction as MLADIS:

- dark navy command bars
- teal and blue active states
- white cards
- soft shadows
- rounded surfaces
- crisp tables
- compact status badges
- clear operational hierarchy
- map and route visuals
- AI assistant panels for staff decision support

## Suggested palette

```text
Command Navy: #061b3a
Ocean Blue: #0077cc
Caribbean Teal: #009a9a
Customs Gold: #f2b544
Success Green: #16a34a
Alert Orange: #f97316
Danger Red: #ef4444

Surface White: #ffffff
Muted Text: #64748b
Primary Text: #0f172a
```

## Typography and density

The platform should feel readable and professional:

- large public homepage headings
- compact operations dashboards
- table text in the 12px-14px range
- card headings in the 14px-18px range
- page titles in the same scale as MLADIS ops pages
- no oversized admin table text
- dense enough for operators, but not visually cramped

## Customer-facing UX

Public pages should prioritize clarity:

- get quote
- track package
- understand shipping steps
- know what documents are required
- contact support
- pay invoices
- receive updates

The customer should always know:

```text
Where is my package?
What do I owe?
What do I need to do next?
Who can help me?
```

## Staff-facing UX

Staff pages should prioritize fast decisions:

- what needs attention now
- which shipments are delayed
- which customs cases need documents
- which deliveries are out today
- which invoices are unpaid
- which customers need follow-up

The staff user should always know:

```text
What changed?
What is blocked?
What needs action?
What can be automated?
```

## AI support direction

809 Shipping should eventually include a shipping/logistics assistant similar to MLADIS FairAgent.

Potential agent roles:

- customer support reply drafting
- customs document checklist guidance
- shipment delay explanation
- route/delivery recommendation
- missing document detection
- invoice/payment follow-up suggestions
- FAQ training and knowledge-base management

AI should suggest and stage actions, but staff should approve consequential customer communication, payments, customs actions, and delivery changes.
